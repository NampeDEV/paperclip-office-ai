# Office Prompt Library

This folder contains the reviewed source prompt for Paperclip AI Office routines. It is not a second scheduler or task store: `scripts/setup-office-reports.mjs` copies the prompt into the native routine description document, where Paperclip versions it with the routine.

The first definition is `office-activity-report.md`. Its schedule is deliberately created disabled. Enable it only after one manual report has an inspectable attachment, matching work product, source counts, and a board review handoff.
